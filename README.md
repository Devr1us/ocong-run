# Ocong Run

Simple endless runner made with Phaser.

## Cara Menjalankan

Buka file `index.html` di browser modern (Chrome/Edge/Firefox). Tidak perlu server untuk demo sederhana.

## Struktur

- `index.html` - entry point
- `sceneMenu.js`, `scenePlay.js` - game scenes
- `assets/` - gambar, audio, sprite, dan partikel

## Lisensi
Gratis untuk dipakai; sesuaikan sesuai kebutuhan.
